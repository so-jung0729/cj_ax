# LSEG (London Stock Exchange Group) — 가공 · 라이선스 · 원페이지

**밸류체인 위치:** ② 가공 · 라이선스. Refinitiv(LSEG)는 토스증권의 해외 투자정보 출처 중 하나다 [F][2]
조사: 2026-11-10 · Aside 세션이 멈춰 공식 실적 발표를 직접 확인 · `[F]` 원문 · `[I]` 해석 · `[U]` 미확인

## 1. 기업 개요
- 런던증권거래소 운영사이자 데이터 · 분석 회사. 데이터 · 분석(Data & Analytics), FTSE Russell, 리스크 인텔리전스, 마켓 사업을 가진다 [F][1]
- 2025년 총수익(회수분 제외) 89.86억 파운드, 전년 84.94억 파운드 [F][1]

## 3. 주요 제품 · 서비스
- 데이터 · 분석 구독 [F][1]
- FTSE Russell 지수 (+7.3%) [F][1]
- **AI 데이터 파트너십:** Anthropic · Databricks · Microsoft · OpenAI · Rogo · Snowflake와 "AI-ready" 라이선스 데이터 제휴 [F][1]

## 4. 최근 동향
1. 2026-02-26 2025년 실적 발표 (회사 발표) [F][1]
2. CEO: "라이선스 받은 신뢰할 수 있는 데이터의 파트너"로 자리매김 [F][1]
3. 회수분(recoveries) 3.60억 파운드 = 고객에게 직접 배포한 **거래소 데이터 같은 제3자 콘텐츠 요금** [F][1]

## 5. 밸류체인 위치
① 원천(거래소 · 제3자)의 데이터를 모아 ② 가공 단계에서 구독으로 판다. 원천의 요금(거래소 데이터 요금)을 고객에게 그대로 넘기는 "회수분"이 따로 있다 [I][1]

## 6. 돈 흐름
- **받는 곳:** 데이터 구독자 (ASV) [F][1]
- **내는 곳:** 거래소 등 제3자 콘텐츠 제공자 → 고객에게 회수 [F][1]

## 7. 데이터 흐름
- 거래소 · 제3자 → LSEG → 증권사 · 플랫폼 · AI 회사 [I][1][2]
- 재배포 조건 · 요금은 비공개 계약 [U]

## 8. 병목 · 비용 신호
- **중간 차감 중첩:** 거래소 데이터 요금이 공급사를 거쳐 회수분으로 다시 고객에게 붙는다 → 플랫폼은 거래소 몫 + 공급사 몫을 함께 낸다 [I][1]
- AI 회사들과 라이선스 제휴 → 데이터 라이선스의 가치가 AI 수요로 오르는 흐름 [I][1]
