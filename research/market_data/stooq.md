# Stooq

## 1. 한 줄 요약
종목별·거래소별 일봉 CSV를 무료로 내려받던 사이트. 하지만 2026-11-10 현재 **스크립트 요청에는 브라우저 검증(JavaScript 작업증명) 페이지가 먼저 뜬다.** 자동 다운로드는 막혀 있어서 **사람이 브라우저로 직접 받는 보조 소스**로만 고려한다. [1]

## 3. 서비스 관점에서 눈에 띄는 점
1. 봇 검증을 우회하지 않는다. 자동화 파이프라인의 소스로는 부적합하다.
2. yfinance 데이터와 값을 대조하는 **교차검증용**(Day 3)으로는 수동 다운로드 몇 종목이면 충분할 수 있다.
3. 이용약관을 확인하기 전까지 서비스 표시용 후보에서 제외한다.

## 4. 확인 필요 항목
- 브라우저로 직접 접속했을 때 일괄 zip 다운로드가 되는지 → **미확인** (사용자가 브라우저에서 확인)
- 이용약관(상업 이용·재배포) → **미확인**
