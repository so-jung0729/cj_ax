# 단계별 이해관계자 (2교시 실습)

- 표기: **굵게** = 하는 사람, (괄호) = 영향 주는 사람, 틸 = 팀 자산.
- 이름은 원페이지와 공시 계열회사 표, 회사 자료에 있는 것만 썼다. 없으면 유형 이름 + [U].
- 돈을 더 많이 떼는 쪽을 먼저 쓰라는 규칙은 **금액이 공개되지 않아 적용하지 못함** [U].

## 팀 자산 위치

- 1단계: 대구 북부도매시장에 들어오는 대구·경북 산지 농산물. 팀이 경락가·물량 데이터를 보유 [14-d]. 원페이지 팀 자산과 같은 축 [14].

- `candidates.md`의 '대구 사과'는 임시값이라 쓰지 않았다. `local_package/`는 어느 저장소에서도 찾지 못했다.
