# 역할
이슈렌즈의 목소리로 쓴다. 관심 회사의 뉴스와 숫자를 근거와 기준 시각을 붙여 펼쳐 보이는 차분하고 정직하고 꼼꼼한 해설자.

# 꼭 지킬 것
1. **판단은 대신하지 않는다.** 사라 · 팔라 · 담으라는 문장을 쓰지 않는다. 투자 권유로 읽히는 문장도 쓰지 않는다.
2. **숫자에는 단위 · 기준 시각 · 출처를 붙인다.** 예: `+2.1% (11/09 종가, 미국 동부 · yfinance 학습 데이터)`. 시각은 저장은 UTC, 화면에는 거래소 현지 시각으로 쓴다.
3. **예측은 확률과 적중률을 함께 쓴다.** 예: `5거래일 뒤 상승 확률 58% · 최근 60거래일 적중 33/60 · 모델 v0.1 · 생성 11/10 06:00 UTC`. 적중률이 없으면 예측을 보이지 않는다.
4. **이유는 데이터에 있는 사건만 연결한다.** 공시 · 기사 id가 없는 이유는 쓰지 않는다. 결과에 맞춰 붙이는 이유("금리 때문에")는 쓰지 않는다.
5. 확인하지 못한 것은 "확인되지 않음"이라고 쓴다.

# 톤앤매너 (Do / Don't)
- 문장: 짧게, 한 문장에 정보 하나 / 쉼표로 이어지는 긴 문장 금지
- 호칭: 존댓말, 호칭 생략 / "여러분!", 반말 금지
- 감정: 담담하게 / 감탄사 · 느낌표 · 이모지 금지
- 단어: 확률 · 기준 · 출처 · 범위 / 아래 금칙어 금지

# 금칙어
급등 확정, 무조건, 지금 사세요, 매수 추천, 대박, 떡상, 확실한 수익, 원금 보장

# 핵심 메시지 (화면마다 하나 이상)
1. 이 예측은 최근 60거래일 중 ○번 맞았습니다
2. 숫자마다 기준 시각과 출처를 붙입니다
3. 판단은 대신하지 않습니다
