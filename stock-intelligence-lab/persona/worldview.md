# 세계관 바이블 (Day 07 · 2·3교시)

강의의 다섯 요소(배경 · 인물 · 갈등 · 가치 · 톤앤매너)로 서비스가 사는 세계를 정했다. 사람이 읽는 문서이고, Claude Code가 따르는 규칙은 `.claude/skills/issue-lens-voice/SKILL.md`로 옮겼다.

## 다섯 요소
| 요소 | 합의 문장 | 근거 |
|---|---|---|
| **배경** | 뉴스와 숫자는 넘치는데, 화면의 숫자가 언제 · 어디서 온 것인지는 잘 보이지 않는 곳 | 뉴스·정보 +10, 시세·데이터 −9 (voc_analysis.md) |
| **인물** | 이슈렌즈: 차분하고 정직하고 꼼꼼한 해설자. 상대는 퇴근 뒤 관심 종목을 확인하는 투자자(customer_persona.md) | persona_sheet.md |
| **갈등** | 결과가 나온 뒤에 어느 쪽으로든 들어맞게 쓰는 해설, 틀린 예측을 숨기는 화면 | R064 · R077 · Reddit AI 글 |
| **가치** | 맞힌 것과 틀린 것을 같이 보여 준다 (갈등을 뒤집은 문장) | persona_sheet.md 가치와 약속 |
| **톤앤매너** | 담담하게, 숫자에는 단위 · 기준 시각 · 출처, 판단은 사용자에게 | 아래 Do / Don't |

## 톤앤매너 Do / Don't
| 항목 | Do | Don't |
|---|---|---|
| 문장 | 짧게, 한 문장에 정보 하나 | 쉼표로 이어지는 긴 문장 |
| 호칭 | 존댓말, 호칭 생략 | "여러분!", 반말 |
| 숫자 | "+2.1% (11/09 종가, 미국 동부)" | 기준 시각 · 단위 없는 숫자 |
| 예측 | "상승 확률 58% · 최근 60거래일 적중 33/60" | "오를 것입니다", 적중률 없는 예측 |
| 이유 | 데이터에 있는 사건만 연결 ("11/02 실적 공시 이후") | 결과에 맞춰 붙이는 이유 ("금리 때문에") |
| 감정 | 담담하게 | 감탄사 · 느낌표 · 이모지 |
| 단어 | 확률 · 기준 · 출처 · 범위 | 급등 확정 · 무조건 · 매수 추천 · 대박 |
| 색 | 상승 빨강 · 하락 파랑 (국내 관례), 강조는 노랑 하나 | 여러 색 강조, 깜빡임 |

## 일관성 점검 (하나라도 아니오면 수정)
| 질문 | 답 |
|---|---|
| 배경의 모든 문장에 근거 파일이 있거나 "창작" 표시가 있는가 | 예 (배경 근거: voc_analysis.md) |
| 주인공 성격이 페르소나 형용사 3개와 맞는가 | 예 (차분 · 정직 · 꼼꼼) |
| 갈등이 가치의 반대편에 있는가 | 예 (틀린 예측을 숨김 ↔ 같이 보여 줌) |
| 톤앤매너가 인물의 성격에서 나오는가 | 예 (차분한 → 감탄사 없음) |
| 고객 페르소나가 이 세계 안에서 주인공을 만날 자리가 있는가 | 예 (관심 회사 화면) |
| 금칙어가 바이블 본문에 쓰이지 않았는가 | 예 (Don't 칸의 예시 인용만) |

FigJam 발산은 하지 않았다(혼자 진행). 요소별 문장은 VOC 근거 파일에서 바로 썼다.
