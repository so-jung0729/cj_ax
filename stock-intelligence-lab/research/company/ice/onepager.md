# ICE (Intercontinental Exchange) — 원천 + 가공 · 원페이지

**밸류체인 위치:** ① 원천(뉴욕증권거래소 운영) + ② 가공 · 라이선스(ICE Data Services). Yahoo Finance의 시세 공급사다 [F][3]
조사: 2026-11-10 · Aside 세션이 멈춰 공식 IR 원문을 직접 확인 · `[F]` 원문 · `[I]` 해석 · `[U]` 미확인

## 1. 기업 개요
- 거래소(NYSE · ICE 선물), 채권 · 데이터 서비스, 모기지 기술 세 부문 [F][1]
- 2025년 연결 순매출 99.31억 달러(+7%), 20년 연속 사상 최대 매출이라고 밝힘 [F][1]

## 2. 사업 모델 6질문
| 질문 | 내용 |
|---|---|
| 누구에게 | 거래 참여자(증권사 · 기관), 데이터 이용자(금융사 · 플랫폼), 모기지 업계 [I][1] |
| 무엇을 | 거래 체결 · 청산, 시세 · 채권 가격 · 참조 데이터, 네트워크 연결 [F][1] |
| 어떻게 전달 | 거래소 시스템, 데이터 피드 · 연결 서비스 [F][1] |
| 어떻게 돈 | 거래 수수료(거래소 거래 수익 순 38.85억 달러) + 반복 매출(구독 · 데이터) [F][1] |
| 무엇으로 | 거래소 라이선스, 체결 데이터 원천, 글로벌 네트워크 [I] |
| 얼마나 | 거래소 54.11억 · 채권 및 데이터 24.19억 · 모기지 21.01억 달러 (2025) [F][1] |

## 3. 주요 제품 · 서비스 (데이터 중심)
- **거래소 데이터 · 연결 서비스** 10.31억 달러(+9%) [F][1]
- **채권 데이터 · 분석** 12.34억 달러 [F][1]
- **데이터 · 네트워크 기술** 7.22억 달러 [F][1]

## 4. 최근 동향
1. 2026-02-05 2025년 실적 발표: 순매출 99.31억 달러, +7% (회사 발표) [F][1]
2. 채권 및 데이터 부문 매출의 약 81%가 반복 매출(19.56억 / 24.19억 달러) [I][1] (원문 수치로 계산)
3. 거래소 부문은 반복 매출이 약 28%, 나머지는 거래 수수료 [I][1]

## 5. 밸류체인 위치
① 원천에서 **체결가가 생기고**, 같은 회사가 ② 가공 단계에서 그 데이터를 정제 · 라이선스로 판다. 원천과 가공을 한 회사가 함께 가진 구조 [I]

## 6. 돈 흐름
- **받는 곳:** 증권사 · 기관(거래 · 청산 수수료), 데이터 이용자(구독 · 연결 요금) [F][1]
- **내는 곳:** [U] (원문에서 데이터 원가 항목을 찾지 못함)

## 7. 데이터 흐름
- 체결 데이터를 직접 만들고, 정제해 Yahoo Finance 같은 플랫폼에 공급 [F][3]
- 재배포 조건 · 요금은 비공개 계약 [U]

## 8. 병목 · 비용 신호
- **라이선스 제약:** 데이터를 쓰는 플랫폼은 ICE와 계약해야 공개 화면에 시세를 보일 수 있다 [I][2][3]
- 데이터 매출이 반복 매출이라는 것은, 플랫폼 입장에서는 **매달 고정으로 나가는 비용**이라는 뜻이다 [I][1]
