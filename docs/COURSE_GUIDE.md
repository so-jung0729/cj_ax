# 강의와 프로젝트 연결 안내

이 문서는 L.L.M Academy Day 01~10의 내용을 수급 레이더에 어떻게 적용하는지 설명합니다. 날짜는 **원래 수업 일정(2026년)**이며, 개인 프로젝트를 같은 날짜에 완료했다는 의미가 아닙니다.

## 강의별 적용

근거 자료는 사용자가 제공한 위 제목의 Day 01~10 강의 PDF입니다. 강의의 예시나 작업 지시를 현재 서비스의 구현 사실로 취급하지 않습니다.

## 수업 내용을 그대로 옮기지 않는 부분

- 원래 수업의 팀 역할과 지역 자산 조사를 개인의 작업 기록, 품목·산지·데이터 조사로 바꾸어 적용합니다.
- 강의의 재고 운영 예시는 주문·재고 등 내부 데이터를 포함합니다. 이 프로젝트의 공공데이터만으로 기업의 실제 재고·발주량을 알 수 있다고 주장하지 않습니다.
- 자료 수집량이나 화면 수는 원래 과제 기준과 개인 프로젝트의 실제 필요를 구분합니다. 개수만 채웠다고 사용자·데이터 검증이 끝나는 것은 아닙니다.
- 인벤토리의 평가 점수는 해석입니다. AI 의견은 사람 두 명의 독립 검토와 같은 검증으로 표기하지 않습니다.
- 브랜드·화면 설계는 아직 계획입니다. 고객과 첫 기능이 구체화되면 작성합니다.

## 현재 작업 순서를 읽는 방법

기업 조사와 밸류체인 분석(Day 09·10)을 먼저 수행한 뒤, 그 결과를 가지고 공공데이터 검증(Day 03의 방법)을 보완하고 있습니다. 강의 번호와 실제 개발 순서가 다른 이유입니다.

현재 확인할 순서는 다음과 같습니다.

1. [기업 비교](../research/company/compare.md)와 [병목 분석](../research/bottlenecks.md)에서 문제 선정 근거를 봅니다.
2. [공공데이터 목록](../research/opendata_catalog.md)과 [데이터 명세](../research/data/data_spec.md)에서 후보 데이터와 실제 확인 결과를 구분합니다.
3. [로드맵](../ROADMAP.md)에서 남은 완료 기준을 확인합니다.
4. [결정 기록](../DECISIONS.md)에서 확정한 내용과 미결정을 구분합니다.

수업 제출 요건, 단독 진행 인정 여부와 제출 일정은 별도 확인이 필요합니다. 이 안내는 제출 완료 확인서가 아닙니다.
