# T03 · 배추·무·양파값 폭락 선제 대응

- URL: https://www.newsis.com/view/NISX20260512_0003625359
- 매체·게재일: 뉴시스 · 2026-05-12 · 수집일 2026-11-09 · 저작권: 요약만 저장
- 근거 수준: 원문 확인 (웹 읽기)

## 요약
- [F] 5월 상순 양파 도매 kg당 504원 — 평년 대비 47.3%, 전년 대비 50.6% 하락. 배추 도매 포기당 2,387원(평년 대비 −21%), 무 도매 개당 1,460원(전년 대비 −35%).
- [F] 원인: 배추·무는 겨울작형 저장량과 봄작형 작황 호조, 양파는 조생종 생산량 증가.
- [F] 대책: 비축 시기 1개월 이상 앞당김, 물량 15% 확대(배추 1만5000t, 무 6000t), 조생종 양파 1만5000t 출하 정지, 할인 행사 최대 40%.

## 이 프로젝트에서
폭락도 위험이라는 근거(인사이트 1). 정부 출하 조절은 가격 변화의 "이유" 후보 — 정책 발표일을 이벤트로 기록할 가치가 있음 [I].
