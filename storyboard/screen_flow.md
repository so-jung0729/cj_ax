# 화면 흐름 v0 — 사용자 여정 → 화면 → 데이터 (Day 08 데이터·서비스 과제)

- 여정 단계 = 훅(발견) · 전개(입력) · 전환(결과) · 행동유도(행동)
- '생기는 데이터' 열 = [events.md](events.md)의 이벤트 명세 초안 · '대시보드 지표' 열 = 퍼널·이용 지표 후보

| 화면 | 여정 | 화면 구성 요소 | 사용자 입력 | 생기는 데이터 | 대시보드 지표 |
|---|---|---|---|---|---|
| 1 알림 · 홈 | 발견 (훅) | 알림 문구 · 오늘 달라진 품목 3개 카드 | 알림 탭 / 앱 열기 | `alert_open`, `app_open` (유입 경로) | 알림 열람률 · 일일 방문자 |
| 2 담당 품목 | 입력 | 품목 칩 6개 · 세그먼트 선택 | 품목 선택 · SG 선택 | `item_follow` (품목 목록) · `segment_set` | 품목별 관심 수 · 세그먼트 분포 |
| 3 알림 기준 | 입력 | 기준(첫 주 대비) · 임계값 슬라이더 | 임계값 입력 | `threshold_set` | 평균 임계값 · 설정 완료율 |
| 4 품목 수급판 | 결과 | 가격선 · 물량 막대 · 기준일 | 기간 변경 | `board_view` (품목·기간) | 품목별 조회 · 체류 시간 |
| 5 산지 | 결과 | 산지 막대 · 최대 산지 비중 | 산지 선택 | `origin_view` (산지) | 산지별 조회 |
| 6 이유 상세 | 결과 (전환) | 이유 카드 · 출처 · 기준일 · 핵심 메시지 | 이유 열기 · 출처 열기 | `reason_open` · `source_open` | **근거 열람률** (핵심 지표) |
| 7 알림 받기 | 행동 | 버튼 1개 · 확인 토스트 | 버튼 탭 | `alert_subscribe` (품목·임계값) | **알림 구독 전환율** |

## 퍼널 (단계 사이 전환율 = 대시보드 지표 후보)

발견 `alert_open` → 입력 `item_follow` → 결과 `reason_open` → 행동 `alert_subscribe`
