# research/ — 리서치 노트 (강의 Day 02~04)

- 용도: 데이터 소스·사용자·경쟁 서비스 조사 노트. **노트 1개 = 대상 1개**, 맨 아래 출처 목록 필수
- 하위 폴더
  - data/ — **모든 데이터의 한 곳**: 정리본 CSV, data_spec.md, archive/(재배포 가능 원본), raw/(커밋 제외), checks/(호출 확인 기록)
  - market_data/ — 주가·거래량·지수 데이터 제공처 노트 (예: alpha_vantage.md)
  - news_data/ — 금융 뉴스·공시 데이터 제공처 (예: gdelt.md, sec_edgar.md)
  - users_competitors/ — 기존 주식 사이트·앱, 사용자 VOC 소스 (예: toss_securities.md)
- 파일명 규칙: 영문 소문자 + 밑줄, 대상 이름 그대로 (keyword_map.md 는 이 폴더 루트)
