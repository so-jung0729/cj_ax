# T01 · 배추값 6월 하순 대비 최대 138% 상승

- URL: https://biz.newdaily.co.kr/site/data/html/2026/07/13/2026071300099.html
- 매체·게재일: 뉴데일리 · 2026-07-13 · 수집일 2026-11-09 · 저작권: 요약만 저장
- 근거 수준: 원문 확인 (웹 읽기)

## 요약
- [F] KAMIS 7월 10일 도매가 기준, 배추 중품 포기당 2,656원으로 6월 하순 1,117원 대비 137.8% 상승. 양배추 +67.7%, 무 중품 +40.8%, 시금치 +34.7%, 대파 +19.3%.
- [F] 청상추·오이·애호박은 하락.
- [F] 6월에는 작황 호조·출하 증가로 낮았다가 7월 장마·폭염으로 반등했다고 설명.
- [F] 수도권 한식당 운영자: 김치·겉절이는 빼기 어려운 반찬이라 다른 채소로 대체할지 고민.
- [F] 원재료 가격이 바로 메뉴 가격에 반영되지는 않고 계약 물량·재고에 따라 시기가 다르다는 업계 설명.

## 이 프로젝트에서
급등·급락 전환(인사이트 1), 대체 품목 고민(인사이트 2)의 근거.
