## 서비스 가설 (아직 미검증, Day 4·9·11에서 검증)
로그인 없이 쓰는 종목 화면:
1. **관심 회사 클릭 → 최근 이슈 키워드** (최근 N일 뉴스에서 뽑은 키워드·이벤트, 뉴스 건수 추이)
2. **우리 모델 예측** (향후 5거래일 방향 확률 + 생성 시각·모델 버전·과거 적중률을 함께 표시)
3. **포트폴리오** (로그인 없이 브라우저에 저장하는 방식 검토. 계정 기반 저장은 후순위)

검증 질문 — 기존 사이트 사용자는:
- 종목 이슈를 파악할 때 어디서, 무엇 때문에 막히는가? (뉴스가 너무 많음? 요약이 없음? 출처를 믿기 어려움?)
- 예측·전망 정보를 볼 때 무엇을 불신하는가? (근거 없음, 적중률 비공개, 광고성 리딩방 등)
- 포트폴리오 기능에서 불편한 점은? (증권사마다 따로 봐야 함, 로그인 필요, 분석 부족 등)

확인할 리스크: 종목별 예측을 공개하면 투자자문·유사투자자문에 해당하는지 (Day 9 리서치 항목, 미검증)
