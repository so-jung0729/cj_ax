# 식품 공급망 공공데이터 목록

> 이 문서는 주제·데이터 후보 선정 당시의 기록입니다. 이후 aT 경매 호출·수집을 진행했으며, 실제 확인 결과와 현재 한계는 [데이터 명세](data/data_spec.md)를 기준으로 함께 읽으세요. 아래 미호출·미확인 표시는 작성 당시 상태입니다.

- 확인일: 2026-11-06 (Aside로 공개 페이지 확인)
- API 키 신청과 실제 호출은 하지 않음. 필드와 제한은 안내 페이지 기준이며, 호출해서 확인해야 함.
- data.go.kr의 "실시간"은 포털 표기임. 관세청 수출입실적처럼 실제로는 월 단위인 경우가 있음.
- data.go.kr 개발계정은 대개 하루 10,000건임("개발 1만건"). 운영 단계 조건은 항목마다 다름.
