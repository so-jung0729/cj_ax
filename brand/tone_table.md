# 톤앤매너 Do / Don't (Day 07)

| 항목 | Do | Don't |
|---|---|---|
| 문장 | 짧게, 한 문장에 정보 하나 | 쉼표로 이어지는 긴 문장 |
| 호칭 | "담당자님", 존댓말 | "여러분!", "사장님들~", 반말 |
| 감정 | 변화의 크기를 숫자로 담담하게 | 감탄사 · 느낌표 · 이모지 |
| 단어 | 평소 대비 · 물량 · 산지 · 기준일 · 범위 | 폭등 · 폭락 · 대란 · 금값 · 역대급 · 확정 |
| 숫자 | 단위 + 비교 기준 + 기준일 ("kg당 402원, 첫 주보다 −45.6%, 11/05 기준") | 기준 없는 퍼센트 ("45% 폭락!") |
| 예측 | 범위와 이유, "가능성" | "반드시 오릅니다", 한 점 예측 |
| 행동 제안 | 정보 제공까지 ("알림을 켜 두면 다시 알려 드립니다") | 구매 지시 ("지금 사세요") |
| 색 · 이미지 | 어두운 바탕, 변화한 값 하나만 강조색, 그래프에 평소선 | 빨강·초록 남발, 과포화, 불꽃·로켓 아이콘 |

## 일관성 여섯 질문 점검 (Claude Code 점검 · 본인 재확인 필요)

| 질문 | 결과 |
|---|---|
| 배경의 모든 문장에 근거 파일이 있거나 "창작" 표시가 있는가 | 예 (figjam_notes 배경 11개 모두 근거 id) |
| 주인공의 성격이 형용사 3개와 맞는가 | 조력자 "레이더"가 차분·정확·먼저 살핌 — 예 |
| 가치를 뒤집으면 갈등이 되는가 | "변화와 이유를 먼저" ↔ "늦게, 이유 없이, 과장되게" — 예 |
| 톤이 인물의 성격에서 나오는가 | 차분한 인물 → 느낌표 없음 — 예 |
| 고객 페르소나가 이 세계에서 주인공을 만날 자리가 있는가 | 아침 시세 확인 시간에 레이더 알림을 받음 — 예 |
| 금칙어가 바이블 본문에 쓰이지 않았는가 | 사건 설명에서 "폭락" 대신 "평년의 절반 가까이" 사용 — 예 (기사 제목 인용은 근거 표에만) |
