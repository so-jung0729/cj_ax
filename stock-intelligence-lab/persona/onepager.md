# 한 장 기획서 (Day 07 · 4교시 + 과제)

아직 시장 분석 전이라 숫자 목표를 쓰지 않는다. 성공 신호는 "무엇이 보이면 됐다고 할 것인가"로 쓴다.

| 항목 | 내용 |
|---|---|
| **제목** | 이슈렌즈 — 관심 회사 한 장 화면 (웹) |
| **핵심 자산** | A03 GDELT(뉴스 제목 · 링크, 상업 이용 가능) · A02 SEC EDGAR(실적 공시 시각, UTC) — top3_rationale.md |
| **대상** | SG1 정보 앱 탐색형: 퇴근 뒤 휴대폰으로 관심 종목의 뉴스와 지표를 확인하는 투자자 |
| **문제 · 욕구** | 숫자가 맞는지 · 언제 기준인지 모른다(시세·데이터 −9). AI 해설을 믿지 못한다(분석 −7, R064 · R077). 가입이 길다(계정·인증 −14) |
| **제공 가치** | 관심 회사를 고른 투자자에게, 최근 이슈와 모델 예측을 근거 · 기준 시각 · 과거 적중률과 함께, 가입 없이 보여 준다 |
| **형태** | 서비스 · 웹 화면 1개 (회사 상세) |
| **핵심 기능 3** | ① 최근 이슈: 기사 제목 · 공시를 시간순으로, 키워드로 묶음 ② 예측 카드: 5거래일 방향 확률 + 최근 60거래일 적중률 + 생성 시각 · 모델 버전 ③ 로그인 없는 관심목록(브라우저 저장) |
| **AI가 하는 일** | 이슈 키워드 추출(요약 · 분류) → 사람이 표본 검사 / 방향 예측(분류 모델) → 백테스트로 검증 / 화면 문구 초안(issue-lens-voice 스킬) → 사람 검토 |
| **성공 신호** | ① 처음 본 사람이 예측 카드의 숫자가 "언제 · 어디서" 온 것인지 바로 말할 수 있다 ② 예측이 틀린 날도 화면이 그대로 그 사실을 보여 준다 |
| **리스크 · 확인** | 화면용 가격 소스 없음(Day 6) · 종목별 예측 공개의 투자자문 해당 여부(Day 9) · 뉴스 이력 11년(학습 기간 제한) · 가설 1(이슈 키워드)은 VOC 근거 약함 |
