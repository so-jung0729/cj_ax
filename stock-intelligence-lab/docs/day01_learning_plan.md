# Day 01 — 개인 학습계획서 (초안)

> 강의 Day 01 템플릿 5항목 기준. **초안이므로 본인 문장으로 다듬을 것** (강의: "내용은 본인 것").
> 12/4 데모데이에서 이 파일을 다시 열어 점검한다.

## 프로젝트 한 줄 소개
**Stock Intelligence Lab** — 주가·거래량과 금융 뉴스를 결합한 딥러닝 분석 결과를, 백테스트로 실제 투자 가치까지 검증해 보여주는 웹 서비스.

## 1. 6주 뒤 나의 모습 (직무 한 가지 기준, 한 문장)
> 실제 금융 데이터를 직접 확보·검증하고, 그 위에 딥러닝 모델과 웹 서비스를 올려 **배포까지 할 수 있는 AI 서비스 개발자**.

## 2. 완성할 결과물 (1개)
- **웹서비스**: 종목 검색 → 주가·뉴스 분석 → 모델 예측 → 전략 백테스트를 볼 수 있는 배포된 대시보드 (URL로 접속 가능)

## 3. 익힐 도구·역량 3가지
| # | 역량 | 확인 방법 |
|---|---|---|
| 1 | Claude Code 기반 리서치·출처 검증 (데이터 소스·라이선스 조사) | `docs/` 아래 출처 등급이 붙은 문서 |
| 2 | 데이터 파이프라인 (API 수집 → 정제 → DB) | `data/metadata.csv`, DB 적재 스크립트 실행 로그 |
| 3 | 웹 서비스화 (FastAPI · React · 배포) | 외부에서 열리는 배포 URL |

## 4. 주간 점검 방법 (매주 금요일 회고)
- 이번 주 커밋된 산출물 수 / 매핑표(`docs/COURSE_GUIDE.md`) 대비 완료 Day 수
- 막힌 점 1~3개와 해결 여부
- "미검증" 표시가 남아 있는 항목 수 (줄어들어야 함)

## 5. 도움이 필요한 영역
- 금융 데이터·뉴스의 **상업적 이용(광고 서비스) 라이선스** 판단
- 웹 배포·보안 (API 키 관리, Supabase/Vercel 설정)

## 세 가지 조건 점검 (강의: 만든다 · 검증한다 · 증명한다)
- **만든다**: 배포된 웹서비스 1개
- **검증한다**: 데이터 출처·라이선스 교차검증, 모델은 기준선·백테스트로 검증
- **증명한다**: 포트폴리오 한 줄 — *무엇을 · AI로 어떻게 · 결과 측정값* (데모데이 전에 채울 것)
