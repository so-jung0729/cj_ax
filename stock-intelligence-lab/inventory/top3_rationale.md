인벤토리 [inventory_v1.csv](inventory_v1.csv) 16개 소스를 [채점 척도](scoring.md)로 매기고, **학습용**과 **서비스 표시용** 저울로 따로 골랐다. 점수는 AI(Claude) 1차 채점이며 본인 캘리브레이션 전이다. 근거 id가 없는 문장은 쓰지 않는다.

## 학습용 Top 3
### 1위 SEC EDGAR (A02)
- **총점:** 공통 4.7 / 학습용 4.9 (D5 · L5 · S4)
- **근거:** `20261110_us_sec_실적공시_01` · research/news_data/sec_edgar.md · crosscheck #11 #13 #14
- **선정 이유:** AAPL 공시 1,006건 + 이전 1,271건(1994~)을 직접 받았고, 접수 시각이 UTC로 확인됐다(#14). 실적 8-K는 항상 16:30 ET에 접수돼 "다음 거래일 반응"으로 라벨을 붙일 수 있다
- **리스크:** 재게시 조건 원문 미확인. 연락처 없는 요청은 403(#13)
- **확인 과제:** 1994~2015 공시 파일 실제 수집, 재게시 조건 원문

### 2위 yfinance · Yahoo 일봉 (A01)
- **총점:** 공통 3.8 / 학습용 4.6 (D5 · L5 · S1)
- **근거:** `20261110_global_yfinance_일봉_01` · research/market_data/yfinance.md · crosscheck #1 #3
- **선정 이유:** 7종목 22~45년, 57,030행. IBM 종가가 Alpha Vantage와 100거래일 100% 일치(#1)
- **리스크:** Yahoo 약관상 개인 용도 · 자동 수집 금지(#3, #4) → **로컬 학습에만**. 상장폐지 종목 없음(생존편향)
- **확인 과제:** 상장폐지 종목 포함 데이터 확보 방법

### 3위 GDELT GKG 2.1 (A03)
- **총점:** 공통 4.4 / 학습용 4.0 (D5 · L3 · S5)
- **근거:** `20261110_global_gdelt_뉴스배치_01` · research/news_data/gdelt.md · crosscheck #16 #17
- **선정 이유:** 기사 제목 · URL · 기관명 · 톤을 15분 단위로 받을 수 있고, DATE가 UTC다(#19)
- **리스크:** 이력이 2015-02부터라 **멀티모달 학습 기간은 약 11년**. 기관명→티커 매핑 필요
- **확인 과제:** 2015년 파일 실제 수집, AAPL 기사 연결 정확도 표본 검사
