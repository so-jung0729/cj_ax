# 수급 레이더

품목과 산지별 가격·물량 이상과 기상 위험을 공공데이터로 한곳에서 보여 주는 개인 사이드 프로젝트입니다. 진행 순서는 `ROADMAP.md`를 따릅니다.

## 범위

- 혼자 진행합니다. 팀 규칙과 팀 시트는 쓰지 않습니다.
- 팀 프로젝트 살피의 코드, 데이터, 브랜드, 캐릭터, 페르소나, 문서는 쓰지 않습니다.
- 데이터는 공공데이터를 기본으로 합니다.
- 결정한 내용과 이유는 `DECISIONS.md`에 남깁니다.

## 보안

- API 키는 `.env`에만 둡니다. 코드, 문서, 커밋 메시지, 대화, 로그에 키 값을 쓰지 않습니다.
- 키 이름은 `.env.example`에 추가하고, 값은 비워 둡니다.
- API 응답을 저장하기 전에 URL에 인증키가 포함되지 않았는지 확인합니다.

## 근거 규칙

- 사실 문장에는 출처 URL과 확인일을 붙입니다.
- `[F]` 원문에서 확인한 사실, `[I]` 해석, `[U]` 미확인으로 구분합니다.
- 숫자는 원문 표기를 유지하고, 계산한 값은 계산이라고 표시합니다.
- 중요한 주장은 독립 출처 2개로 확인합니다. 같은 보도자료를 인용한 기사는 하나로 셉니다.
- 찾지 못한 내용은 지어내지 않고 `[U]`로 남깁니다.

## 수집 규칙

- 웹 수집은 Aside를 사용합니다.
- 로그인이 필요한 자료와 유료 자료는 수집하지 않습니다.
- 기사와 글은 요약만 저장하고, 사람 이름과 닉네임은 역할로 바꿉니다.
- 원본 데이터는 `research/data/raw/`에 그대로 두고, 정리본은 `research/data/`에 저장합니다.
- 수집물마다 소스, URL, 일시, 저작권을 기록합니다.

## 표현 규칙

- 예측은 확정처럼 쓰지 않고 범위, 근거, 데이터 기준일과 함께 씁니다.
- 구매나 투자를 지시하는 표현을 쓰지 않습니다.

## 작업 방식

- 결과는 대화가 아니라 파일로 남깁니다.
- AI가 만든 결과는 표본을 정해 사람이 원문과 대조합니다.
- 작은 단위로 커밋하고, 키와 원본 대용량 파일이 포함되지 않았는지 확인합니다.
