## 4. 결정

- **첫 대상은 SG1**입니다. 근거가 가장 많고(원문 확인 J01), ROADMAP의 첫 사용자 가설(중소 식품 제조사·식자재 유통사 구매 담당자)과 같습니다.
- SG2·SG3는 같은 데이터를 쓰되 화면 문구와 알림 빈도만 다르게 둘 후보입니다.
- 대시보드 필터: `segment ∈ {SG1, SG2, SG3}` — 첫 버전은 가입 때 본인이 고르는 방식 (행동 기록으로 자동 분류는 사용자 데이터가 생긴 뒤).
